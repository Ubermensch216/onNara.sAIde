# 구현 현황

기준일: 2026-09-20

## 완료된 구현 사항

### 1. 기반 아키텍처 및 보안 체계
- 참조 프로젝트와 완전히 분리된 독립 `onnara-saide` 패키지 구성 및 메타데이터 구축
- Microsoft Edge MV3(`wxt build -b edge`, Edge 116+) 빌드 파이프라인 및 `.output/edge-mv3` 검증기 구축
- Ollama(로컬) 및 범정부 AI 공통기반 연계를 위한 공통 공급자 인터페이스 정의 (`lib/llm/provider.ts`) — **계약과 설정 해석기까지 완료, 런타임 배선은 미완**(아래 "아직 구현하지 않은 범위" 참조)
- 기관 관리 정책(`chrome.storage.managed`)과 사용자 설정을 분리해 해석하는 설정 우선순위 계층 (`lib/llm/config.ts`)
- 공개 환경변수 빌드 차단 검사(`scripts/check-public-env.mjs`)로 민감키 번들 포함 원천 방지
- 행정 블루 라이트·다크 디자인 토큰 적용 및 WCAG AA 자동 색상 대비 검사 통과 (13개 쌍 통과)
- Fail-Closed 원칙의 외부 전송 판정 함수(`lib/llm/transfer-policy.ts`) 정의 — **호출 지점은 외부 공급자 도입 시 연결 예정**
- 패널 헤더에 처리 위치와 모델을 함께 보이는 칩(`내 PC · gemma4:e2b`) 표시. 현재 추론 경로는 로컬 Ollama 한 갈래다

### 2. 온나라 연동 및 문서 수집 (DOM / iframe / PDF)
- 온나라 2.0 접수대기함·문서등록대장 표의 머리글과 행을 탐색하는 DOM 추출기 구현
- 중첩된 접근 가능 iframe을 재귀 탐색하고 문서 목록 프레임을 우선 식별
- 목록의 특정 제목 또는 체크된 문서에 대해 임시 백그라운드 탭을 열어 본문을 회수하고 탭 자동 정리
- 동일 iframe 이동, 탭 전환, 팝업 상세 화면을 모두 감시하고 예외 시 안전하게 복구
- 여러 문서 처리 시 복제 작업 탭을 끝까지 재사용하여 리소스 낭비 최소화
- 브라우저 PDF 뷰어로 표시되는 공문 대응: 프레임에서 원본 수신 → 오프스크린 문서의 `PDF.js`로 텍스트 추출 → 화면 메타데이터와 병합 (한국어 CMap 동봉)
- 사이트 권한이 없는 외부 프레임(전용 뷰어 등) 발견 시 대기 지연 없이 오류 배너 및 "권한 허용" 원클릭 버튼 제공

### 3. 사이드패널 사용자 인터페이스 및 세션 관리
- 사이드패널을 **AI 탭**·**일정 탭**·**도구 탭**으로 명확히 분리
- AI 답변마다 **`AI 생성 · 검토 필요`** 배지 부착으로 환각에 대한 사용자 주의 환기
- 탭이나 온나라 페이지를 이동해도 문서별 작업 세션과 읽은 본문, 진행 상태가 유지되는 세션 캐시 구현
- 대화 메시지별 복사/삭제 아이콘 및 현재 세션 안전 초기화 기능
- 장시간 소요되는 LLM 추론 중에도 불필요한 자동 타임아웃을 배제하고 사용자 취소(Abort) 지원

### 4. `/`·`@` 두 갈래 명령 체계 및 문맥 격리
- **접두 문자로 결과가 남는 곳을 구분**: `/`는 AI 창 안에서 끝나는 명령, `@`는 다른 탭에 남는 것(일정 항목·다운로드 작업)을 다루는 명령
- **자동 화면 전환 없음**: `@` 명령을 실행해도 AI 창에 머무른다. 결과 안의 링크를 눌러야 해당 탭으로 이동하며, **그 항목이 강조·스크롤된 상태**로 열린다 (`lib/panel/links.ts`)
- `/` 그룹 — 문서등록대장 목록 제어:
  - `/요약` (`/summary`): 체크 문서 순차 읽기 및 개별 요약
  - `/조치` (`/actions`): 핵심·조치사항 카드 생성
  - `/비교` (`/compare`): 선택 문서 동시 분석 및 공통/차이점 비교
  - `/읽기` (`/read`): 요약 없이 본문만 추출하여 대화에 첨부
  - `/새로고침` (`/refresh`): 목록 현황 및 체크 상태 재조회
  - `/기억` (`/recall`, `/memory`): 저장된 기억에서 검색 (설정에서 기억을 켠 경우에만 동작)
- `@` 그룹 — 다른 탭이 주화면:
  - `@일정` (`@schedule`): 자연어 일정 관리 → 일정 탭 (S07, 아래 8항)
  - `@첨부` (`@attach`): 첨부파일 일괄 다운로드 → 도구 탭 (기존 `/첨부`에서 이관)
- **이름이 옮겨 가도 막히지 않는 자동완성**: 접두 문자가 어긋나면(`/첨부`) 반대 그룹에서 찾아 새 이름(`@첨부`)을 보여 주고, 그대로 Enter를 눌러도 인자까지 살려 실행
- **문맥 경계 (`contextFrom`)**: 목록 명령 실행 또는 본문 교체 시점을 기준으로 이전 대화는 보존하되 모델 전송 문맥에서 분리하여 토큰 절약 및 문맥 오염 방지
- 명령 없는 일반 입력은 현재 대화 문맥만을 활용하여 즉답하는 프롬프트 처리

### 5. 핵심·조치사항 카드 (Action Card · S01)
- 공문의 요지, 할 일(To-Do), 제출물, 마감 기한, 문의처, 근거 문장을 JSON 스키마로 구조화 출력
- 시스템 코드가 원문 텍스트와 기한 날짜 및 근거 문장을 대조하여 `원문 확인` 또는 `원문에서 찾지 못함` 배지 검증
- 모델이 놓친 "~까지", "~일한" 등 정규식 기반 기한 문장을 코드가 원문에서 직접 탐색하여 보정

### 6. 자동화 도구 탭 및 안전 승인 시스템
- 첨부파일 순차 다운로드: 브라우저 완료 신호를 감지한 후 다음 파일로 안전하게 순차 진행
- 대용량 링크 첨부(`.html`) 자동 인식: 파일명 뒤에 확장자 구분점 없이 결합되는 링크 첨부(예: `...hwpx(link).html`)를 첨부 목록에서 식별하고 수신 처리
- 자동화 작업 대기열(Queue) 및 패널 재시작 후에도 유지되는 영구 실행 기록
- 다운로드 완료 항목의 `파일 열기` 및 `폴더 열기` 연동
- 에이전트의 브라우저 클릭/입력/이동 시 사전 확인을 강제하는 사용자 승인 카드(`ApprovalCard`) 탑재
- `pdfjs-dist`를 6.3.289로 업그레이드하여 알려진 보안 취약점(CVE-2026-16633) 선제적 해소

### 7. 일정 탭 — 기한·후속조치 보드 (S07)
- 공문식 기한 표기(`2026. 9. 30.(수)`, `9월 30일 18:00까지`, `2026-09-30`)를 달력 날짜로 정규화하는 파서 구현
- 연도가 생략된 기한은 **문서 보고일자를 기준일로 삼아** 해석하고 `연도 추정` 배지로 추론 사실을 표시(60일 유예로 이미 지난 기한이 다음 해로 밀리지 않도록 보정)
- 핵심·조치사항 카드의 할 일·기한·원문 대조 결과를 그대로 물려받는 일정 후보 생성기(모델이 빠뜨려 코드가 찾은 기한도 후보로 승격)
- AI 답변 아래 **`일정으로 등록`** 확인 카드: 근거를 확인한 후보만 기본 체크, 미확인 후보도 지우지 않고 사용자가 직접 체크해 등록, 자동 등록 경로 없음
- 같은 공문 재분석 시 중복 등록을 막는 키(`공문 제목 + 할 일`)와 기존 항목 보존(메모·완료 표시 덮어쓰지 않음)
- 월·주·일 달력 보기와 D-day 목록 보기 전환(마지막 보기 방식 기억), 월 격자는 어느 달이든 6주 42칸 고정
- 월 격자 칸에 일정 2건 + `+n` 표시, 지난 기한은 붉은 칩·점, 완료는 취소선, 날짜를 누르면 격자 아래에 그 날 일정 전개 및 그 날짜로 바로 추가
- 기한 미정 항목은 달력 칸에 넣지 않고 건수 띠로 남겨 목록 보기로 연결(없는 기한을 만들지 않으면서도 잊히지 않게)
- 기한 지남 · 오늘 · 이번 주 · 나중 · 기한 미정 · 완료 구간의 D-day 목록 뷰, 지난 기한은 `D+n`으로 상단 유지
- 완료 체크, 직접 추가·수정·삭제(확인 후), 근거 문장·제출물·문의처 펼쳐보기, 출처 공문 새 탭 열기
- 대화와 분리된 수명의 Dexie v3 `tasks` 테이블(대화를 지워도 기한은 남음) 및 v1→v3 마이그레이션 검증
- `chrome.alarms` + `chrome.notifications` 기반 기한 알림: 사이드패널을 닫아도 동작, 하루 한 번 지난 기한·오늘·내일을 묶어 알림, 알림 시각 설정 가능
- CSV(근거 문장 포함·수식 주입 방지·BOM) 및 ICS(`TZID=Asia/Seoul`, 남은 기한만) 내보내기

### 8. `@일정` — 자연어 일정 관리 (S07 · 참조 프로젝트 myAI 캘린더 이식)
- 참조 프로젝트(`myAI`)의 서버측 의도 분류기(`server/calendarAgent.js`)를 **확장 내부로 이식**: 서버 없이 패널에서 Ollama를 직접 호출하고, 자유 JSON(`format:"json"`) 대신 **JSON 스키마 구속** 적용으로 파싱 실패율 저감
- 의도 5종 분류(`schedule.create` / `list` / `update` / `delete` / `chat`) 및 페이로드 정규화·검증 계층 (`intent.ts`)
- **모델은 분류만 수행**: 사용자가 읽는 목록과 답변 문장은 코드가 IndexedDB를 직접 읽어 생성 (`report.ts`). 대화 모델에 일정 목록을 맡겼을 때의 환각 경로를 원천 차단
- **결정적 날짜 해석기** (`nl-date.ts`): 오늘·내일·모레·이번 주·다음 달·`N월 N일`·`N월부터 M월까지`·`YYYY년도` 등을 코드가 직접 추출하고, 모델이 축소한 조회 범위를 이 값으로 보정
- **쓰기 전 확인 카드 강제** (`ScheduleIntentCard`): 등록·수정·삭제는 예외 없이 사용자 확인을 거침. 자동 저장 경로 없음(참조 프로젝트는 충돌이 없으면 즉시 기록했으나 해당 동작은 미이식)
- **대상 추측 금지**: 제목이 여러 건에 걸리면 전부 제시하고 사용자가 선택. 단일 건일 때만 기본 체크하며, **범위 삭제는 "전부"로 지시해도 기본 체크하지 않음**(비가역 동작)
- 항목별 변경 전/후 대비 표시, 중복 등록 경고(차단하지 않고 고지), 완료 표시는 `setTaskDone` 경유로 완료 시각 일관성 유지
- **결과 안의 딥링크**: 항목 제목이 곧 일정 탭의 그 항목으로 가는 링크이고, 목록 아래에는 **물어본 범위 그대로**(하루→일, 한 주→주, 한 달→월) 펼치는 링크가 붙는다 (`ScheduleFocus` / `AutomationFocus`)
- 링크 문법을 한 곳(`PANEL_LINK_URI_PATTERN`)에 두고 DOMPurify 허용 목록이 같은 값을 쓰도록 묶어, 링크가 조용히 제거되는 경로를 테스트로 차단
- 지운 항목에는 링크를 걸지 않는다(갈 곳이 없는 링크는 "아직 남아 있나?"라는 의심만 남긴다)
- 분류 호출은 독립 1회성 요청(시스템 프롬프트 + 문장 1개, `temperature: 0`, `num_ctx` 4096 상한)으로 공문 대화의 KV 캐시 접두사를 훼손하지 않음
- 이벤트 모델(시작·종료 시각, 종일, 장소, 색, 반복, 알림)은 업무 항목 모델과 맞지 않아 미이식. 반복 일정은 후속 단계로 유보

### 9. 생산성·신뢰 보완 (서비스 진단 B1~B5 · B9)

- **분석 결과 캐시 (B1)**: 문서 정체성(목록 이름 + 제목 + 보고일자)과 본문 해시로 `/요약`·`/조치` 결과를 보관. **본문은 언제나 다시 읽고**, 본문 판본이 같을 때만 모델 호출을 건너뛴다(정정 공문에 지난 요약이 붙는 경로를 원천 차단). 재사용한 답변에는 `(날짜) 분석 결과 재사용` 배지, 입력창 위에는 `다시 분석` 버튼. 지시문·모델이 다르면 다른 결과로 취급하며 상한(300건) 초과 시 오래된 것부터 정리
- **AI 작업의 작업 큐 이관 (B2)**: `AutomationKind`에 `summarize`·`actions` 추가. 첨부 다운로드와 같은 대기열에 서므로 온나라 작업 탭 경합이 사라지고, 도구 탭에서 진행·취소·기록이 보인다. 본문 읽기가 안쪽에서 이미 잠그므로 바깥 잠금을 걸지 않는다(`lock: false` — 교착 방지 시험 포함). 30초를 넘긴 작업이 끝나면 `chrome.notifications`로 알림(설정에서 끌 수 있음)
- **첫 실행 안내 (B3)**: 3장짜리 안내(목록 체크 → 명령 / `/`와 `@`의 차이 / 기한을 일정 탭으로). 어느 장에서든 건너뛰기·`Esc`로 닫히고, 판(version) 관리로 명령 체계가 바뀔 때만 다시 띄운다. 설정의 `사용법 다시 보기`로 재호출
- **정확도 피드백 (B4)**: AI 답변과 기한 후보에 `맞음`·`틀림` 1클릭. 같은 대상에 다시 누르면 덮어쓰고, 같은 버튼을 다시 누르면 취소된다. 설정 화면에 누적 정확도와 대상별(핵심·조치사항 / 기한 후보 / 문서 요약) 표. 표본이 적으면 수치 옆에 그 사실을 밝히고, 평가가 없으면 0%가 아니라 "없음"으로 표시. 공문 제목을 포함해 어떤 내용도 기록하지 않으며 외부 전송 없음
- **첨부 파일명 정규화 (B5)**: `보고일자_공문제목_원래이름`으로 저장(설정에서 끄거나 공문별 하위 폴더 선택 가능). `chrome.downloads.onDeterminingFilename`으로 **직접 URL과 화면 클릭 두 경로를 한 곳에서** 덮는다. 확장자는 브라우저가 정한 값을 그대로 유지하고, 경로 구분자·상위 참조는 제거하며, 예약은 한 번만 쓰이고 30초 후 만료(사용자가 직접 받은 파일이 개명되는 사고 방지)
- **하이브리드 검색 (B9)**: 벡터(코사인)와 키워드(BM25) 순위를 각각 내어 RRF로 융합. 한국어 조사 대응을 위해 낱말과 한글 2-gram을 함께 색인하고, `2026-1234호`처럼 벡터가 가리지 못하는 정확 일치를 키워드가 끌어올린다. 임베딩 실패 시 키워드 단독으로도 검색된다. 역색인 테이블을 더하지 않아 스키마 변화 없음
