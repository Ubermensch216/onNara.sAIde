# 구현 현황

기준일: 2026-09-17

## 완료

- 참조 프로젝트와 분리된 `onnara-saide` 작업 디렉터리 생성
- 제품명과 한·영 확장 메타데이터 독립화
- Microsoft Edge 전용 개발·빌드·ZIP 명령 구성
- Edge MV3 산출물 검증기 추가
- Ollama와 범정부 AI 공통기반용 비밀값 없는 `.env.example` 작성
- 외부 전송·로컬 보존 기본 정책 명시
- 공급자 공통 계약과 설정 우선순위 해석기 구현
- 기관 관리 정책(`chrome.storage.managed`)과 사용자 설정 저장소 분리
- 행정 블루 라이트·다크 토큰과 WCAG AA 자동 검사 적용
- 공개 환경변수 비밀값 빌드 차단 검사 적용
- 온나라 문서 키, 화면 종류, 실행 컨텍스트, 어댑터 선택 계약 구현
- TypeScript 검사, 354개 테스트, Edge MV3 빌드·검증·ZIP 생성 완료

## 진행 순서

1. Ollama 공급자 어댑터를 공통 계약에 연결하고 모델 선택 UI 구현
2. 실제 온나라 HTML 표본으로 화면 어댑터와 iframe 수집기 구현
3. 문서함 브리핑, 배부 추천, 개인정보 점검 MVP 구현
4. 범정부 AI 공통기반 명세 확보 후 공급자 어댑터 추가
5. 실제 온나라 계정에서 호환성·보안·접근성 검증
