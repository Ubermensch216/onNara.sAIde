# 구현 현황

기준일: 2026-09-17

## 완료

- 참조 프로젝트와 분리된 `onnara-saide` 작업 디렉터리 생성
- 제품명과 한·영 확장 메타데이터 독립화
- Microsoft Edge 전용 개발·빌드·ZIP 명령 구성
- Edge MV3 산출물 검증기 추가
- Ollama와 범정부 AI 공통기반용 비밀값 없는 `.env.example` 작성
- 외부 전송·로컬 보존 기본 정책 명시
- 공급자 공통 계약과 설정 우선순위 해석기 구현
- 기관 관리 정책(`chrome.storage.managed`)과 사용자 설정 저장소 분리
- 행정 블루 라이트·다크 토큰과 WCAG AA 자동 검사 적용
- 공개 환경변수 비밀값 빌드 차단 검사 적용
- 온나라 문서 키, 화면 종류, 실행 컨텍스트, 어댑터 선택 계약 구현
- Ollama를 공급자 공통 계약에 연결하고 외부 전송 판정 게이트 구현
- 패널 헤더에 현재 로컬 모델과 처리 위치 표시
- 받은문서 표의 헤더·행을 DOM에서 구조화하는 추출기 구현
- 접근 가능한 온나라 iframe 전체를 탐색하고 문서 목록 프레임을 우선 선택
- 받은문서 제목 표 요청 시 자동 재수집 후 결정론적 Markdown 표 응답
- 목록의 특정 제목 요약 요청 시 제목을 결정적으로 대조하고 임시 백그라운드 탭에서 상세 문서 본문 회수
- 동일 iframe 이동·같은 탭 이동·팝업 상세 화면을 감시하고 성공·실패 시 임시 탭 자동 정리
- 임시 탭 활성화 이벤트가 패널 대화를 전환하던 경쟁 조건 수정. 질문을 읽기 전에 저장하고 진행·오류 상태 표시
- 체크한 문서 및 현재 페이지 전체 문서의 순차 읽기·요약, 진행 건수 표시 지원
- 페이지·탭 전환 시 문서별 작업 세션 유지 및 본문·진행·결과 복원, 해당 문서의 최신 저장 대화 조회 수정
- 사용자·AI 메시지별 복사·삭제 아이콘, 현재 세션 초기화 아이콘 및 취소된 응답의 늦은 저장 방지
- 일반 대화·에이전트의 LLM 응답 대기 시간 제한 제거, 기존 무응답 설정 무시 및 사용자 중단 유지. 문서 읽기 120초 등 브라우저 작업 제한은 별도 적용
- 복제 시 초기화되는 목록 iframe·조회 폼 조건 복원, 대상 제목이 있는 프레임 우선 탐색, 숨긴 전체 제목과 생략된 제목 링크 연결 수정 (기관 환경 검증 필요)
- 일반 HTTP(S) 첨부 링크 탐지 및 파일별 완료 확인 후 순차 다운로드. 스크립트·전용 프로그램 방식은 미지원, 실제 온나라 다운로드 미검증
- 사이드패널을 AI·도구 탭으로 분리. 답변마다 "AI 생성 · 검토 필요" / "자동화 실행 기록" 출처 표시
- 자동화 작업 대기열·실행 기록(패널 재시작 후에도 유지)과 작업 탭 잠금. AI 대화의 첨부 다운로드도 같은 대기열 사용
- 자동화: 선택 문서 첨부 받기, 파일 열기·폴더 열기. 도구 탭을 작업 대상 → 실행할 작업 → 진행 중 → 실행 기록 순으로 재배치 (목록 내보내기는 제거)
- PDF 뷰어로 표시되는 공문 본문 읽기: 프레임에서 PDF 원본 수신 → 오프스크린 문서의 pdf.js로 글자 추출 → 화면 글자와 병합. 한국어 CMap 동봉, 실패 시 사유 표기 (실제 온나라 뷰어 미검증)
- 문서 열기 대상 식별 보완: 목록 추출과 같은 기준으로 머리글·행을 읽고, 같은 제목이 여러 행이면 체크한 행 우선. 제목이 줄어 보이는 목록도 대조. 실패 시 원인(겹치는 행 수·현재 목록 제목 예)을 오류 힌트로 표시
- 여러 문서 견주어 보기(공통점·차이점·비교): 문서별 요약으로 새지 않고 한 번에 답변. 앞선 답변이 있으면 재읽기 없이 그 내용으로 답하고, 없으면 본문 예산을 나눠 함께 읽음
- 입력 체계 재구성: 슬래시 명령을 문서등록대장 목록 제어 전용(/요약·/조치·/비교·/읽기·/첨부·/새로고침)으로 교체. 문장으로 의도를 짐작하던 판별기(요약·첨부·조치·표·비교)를 모두 제거하고, 슬래시 없는 입력은 대화 문맥만 쓰는 일반 프롬프트로 처리. 웹페이지 본문 명령과 목록 제목 표 기능은 삭제
- 문맥 경계(contextFrom): 문서 명령 실행·본문 떼기 시점 이후의 대화만 모델에 전달. 대화 레코드에 저장해 패널 재시작 후에도 유지
- 문서 전환 중 보낸 요청이 사라지던 경쟁 조건 수정: 대화 복원·세션 선택이 끝난 뒤 지금 보이는 대화에서 실행
- AI: 핵심·조치사항 카드(S01). JSON 스키마 출력, 근거 문장·기한 날짜 원문 대조, 누락된 "…까지" 기한 코드 보완
- 여러 문서 처리 시 복제 작업 탭 재사용, 요약·첨부 동시 요청 시 문서당 한 번만 열기, 권한 없는 본문 프레임 즉시 안내
- TypeScript 검사, 447개 테스트, Edge MV3 빌드·검증 완료. 가짜 온나라 사이트와 실제 Chromium·gemma4:e2b로 흐름 검증(실제 온나라 미검증)

## 진행 순서

1. 기능별 모델 선택 UI와 공급자 레지스트리 연결
2. 실제 온나라 HTML 표본으로 화면 어댑터와 iframe 수집기 구현
3. 문서함 브리핑, 배부 추천, 개인정보 점검 MVP 구현
4. 범정부 AI 공통기반 명세 확보 후 공급자 어댑터 추가
5. 실제 온나라 계정에서 호환성·보안·접근성 검증
