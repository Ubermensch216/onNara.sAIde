# 2026-10-07 보안·안정성 보완

## 적용 범위

- 기안기 호스트는 확장 iframe의 출처와 발신 창이 모두 일치하는 메시지만 받는다. 확장 스킴의 origin이 null로 표시되는 환경에서도 확장 ID를 비교하며, 불투명한 출처는 거절한다. 제목·본문 길이와 삽입 모드를 검증한다.
- 서비스 워커의 기안 특권 요청은 실제 기안 탭에 속한 콘텐츠 스크립트 송신자만 받는다. 버블 AI의 주소와 모델은 송신자가 제공한 값 대신 저장된 설정을 사용한다.
- 클릭 위치 지정 삽입에는 미리보기 확인을 추가했다. 합성 클릭은 승인으로 보지 않으며, 문서·본문·대상 변경을 확인한다. 제목·요약 등 문서 정보 필드에는 본문 초안을 넣지 않는다. 실패·수동 복사 경로를 삽입 성공으로 표시하지 않고 미확인 붙여넣기 시도를 제거했다.
- AI HTTP 호출은 공통 주소 검사로 연결했다. 루프백 이외 서버는 주소별 사용자 승인 또는 기관 허용 정책을 적용한다. 기관 차단과 서버 주소 고정이 우선하며, 정책 읽기 실패 시 요청을 보내지 않는다. 리다이렉트와 쿠키 전송을 차단한다. 원격 승인 기록은 백업에서 제외한다.
- 주민번호 형태·휴대전화·이메일·이미지 입력의 개인정보 가능성을 외부 전송 판정에 연결했다. 정규식 기반의 보수적 탐지이며 정밀 개인정보 점검 또는 무누락 보장을 뜻하지 않는다.
- 실제 AI 서버 위치를 패널에 표시하고, 관리형 정책 스키마를 패키지에 포함했다. 지원하는 관리 정책은 아래 예시의 두 항목이다. 범정부 AI 공급자 및 기능별 모델 정책 배선은 후속 범위다.
- 모델 답변 HTML에서 임의 class와 style을 제거하고 CSP로 외부 이미지·글꼴·프레임 로드를 제한한다. 신뢰한 코드 하이라이터의 서식은 별도 렌더링한다.
- 교차 출처 top.document 접근이 거부되면 현재 프레임의 DOM으로 판정한다.
- 문맥 구성과 전송 검사의 토큰 추정 기준을 맞췄다. 고정 본문과 최신 질문이 예산을 넘으면 입력을 조용히 자르지 않고 오류로 알린다. 토큰 수는 추정치이며 모델별 실제 토크나이저 보장은 아니다.
- TONGDAL 취소·시간 제한을 응답 본문 읽기까지 유지한다. 이미 취소된 요청은 보내지 않는다.
- 버블 추론은 오프스크린 문서에서 실행하고 요청별 실제 취소를 연결한다. 취소는 발신 탭·프레임·문서에 묶이며 문서 이동·종료 시 해당 요청을 취소한다. PDF와 AI가 동시에 사용할 때 마지막 작업이 끝나기 전에는 오프스크린 문서를 닫지 않는다.
- 분석 캐시를 서버 주소 및 분석 로직 판본으로 분리했다. 프롬프트나 원문 검증 로직이 바뀌면 DOC_ANALYSIS_VERSION을 올린다.

## 관리 정책 예시

아래는 관리형 저장소의 논리 구조다. 실제 OS별 설치 정책 등록은 기관 배포 방식에 맞춰야 한다.

```json
{
  "onnara.saide.policy": {
    "externalEgressPolicy": "block",
    "providers": {
      "ollama": { "endpoint": "http://127.0.0.1:11434" }
    }
  }
}
```

externalEgressPolicy의 block은 루프백 이외 AI 서버 전송을 차단한다. confirm은 주소별 사용자 승인을 요구한다. allow는 기관 허용을 적용하지만 개인정보 가능성이 탐지된 입력은 사용자 주소 승인을 추가로 요구한다. 기존 원격 서버 사용자는 업데이트 후 설정 화면에서 주소를 확인해 승인해야 한다. 원격 주소를 다시 입력한 뒤 입력란을 벗어나면 확인 절차가 열린다.

## 검증 및 남은 범위

타입 검사와 전체 123개 파일·1,350개 단위·DOM 회귀 테스트가 통과했다. 참고문서 전송 정책의 최종 집중 테스트 45개도 통과했다. Edge·Chrome 프로덕션 빌드, Edge 배포 파일 검증 및 13개 색상 쌍의 WCAG AA 대비 검증을 통과했다. 별도 Edge 프로필의 headless 자동 확인은 CDP Runtime.enable 응답 시간 초과로 완료하지 못했다. 이 기록은 실제 온나라·WebHWP·TONGDAL 종단 검증 완료를 의미하지 않는다.

기관 환경에서 다음을 확인해야 한다.

1. 기안 드로어의 맥락 수신, 제목 반영 및 클릭 삽입 확인·취소·실패 안내.
2. 같은 출처 및 다른 출처 iframe의 선택 버블, 문서 이동 중 취소, PDF 분석과 AI 변환 동시 사용.
3. 콜드 모델, 5분 이상 장시간 추론, 서비스 워커 재시작 및 브라우저 종료 시 동작.
4. 실제 기관 정책 등록·변경, 원격 승인·차단, TONGDAL 페어링·검색 및 취소.

모든 사이트 권한의 기관별 제한, 영속 작업 큐 복구, 데이터 종류별 보관 정책, 공급자 선택 UI 및 대규모 모듈 분리는 후속 개선 범위로 남는다. 이번 변경에서 localContentRetention 설정을 실제 저장 정책으로 집행했다고 보아서는 안 된다.
