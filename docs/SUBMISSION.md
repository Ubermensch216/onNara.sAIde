# 심사 제출 패키지 안내 (구동 안내서)

기준일: 2026-11-18 · 버전: 0.1.0

「2026년 AI 활용 우수사례 공모전」 심사용으로 제출하는 **온나라 sAIde(onNara.sAIde)**의 패키지 구성과 구동 방법입니다. 서비스의 기능·구현 범위는 [README](../README.md)와 [구현 현황](IMPLEMENTATION_STATUS.md)에 있습니다.

## 1. 제출 파일

`npm run release`(또는 아래 §5의 개별 명령)로 `release/` 폴더에 만들어집니다.

| 파일 | 내용 |
|---|---|
| `onnara-saide-0.1.0-source.zip` | **소스 패키지.** 소스코드·시험·문서·화면 캡처·문서용 미리보기(모의데이터 포함). `node_modules`, 빌드 산출물, 비밀값(`.env.local`)은 들어 있지 않습니다. |
| `onnara-saide-0.1.0-edge.zip` | **배포용 확장 프로그램**(Microsoft Edge, Manifest V3). 압축을 풀어 `edge://extensions`에서 불러오면 바로 설치됩니다(빌드 불필요). |
| `SHA256SUMS.txt` | 위 두 파일의 SHA-256 해시와 크기 |

소스 패키지의 최상위 폴더(`onnara-saide-0.1.0/`) 구성:

| 경로 | 내용 |
|---|---|
| `src/` | 확장 프로그램 소스(TypeScript·React). `entrypoints/`(사이드패널·기안 사이드카·백그라운드·옵션), `lib/`(AI·온나라 연동·저장소·서식 분석 등) |
| `docs/` | 구현 현황, 보완 기록, **화면 캡처**(`screenshots/`), 소개 인포그래픽, **문서용 미리보기**(`preview/`) |
| `plan/` | 구축 계획서 |
| `scripts/` | 빌드 검증·색상 대비 검사·미리보기 서버·패키징 스크립트 |
| `public/`, `brand/` | 아이콘·정책 스키마·안내 영상 / 브랜드 자산 |
| `package.json`, `package-lock.json`, `wxt.config.ts`, `tsconfig.json`, `vitest*.ts`, `.env.example`, `.nvmrc` | 빌드·시험 설정과 환경 변수 견본 |

## 2. 실행 환경

| 구분 | 요구 사항 |
|---|---|
| 화면 확인(방법 A) | Node.js 24.x(`.nvmrc` 24.18.0), npm 11.x, 최신 Edge 또는 Chrome. **온나라 계정·AI 모델 불필요** |
| 확장 설치(방법 B) | Microsoft Edge 116 이상. AI 기능을 쓰려면 Ollama 0.34 이상과 모델 `gemma4:e2b`(약 6.7 GB), `bge-m3:latest`. 온나라 연동 기능은 **온나라 2.0 로그인 상태**가 필요 |

## 3. 구동 방법

### 방법 A. 화면 확인용 — 온나라 계정·AI 모델 없이 (심사 권장)

소스 패키지를 풀고, 그 폴더에서 PowerShell을 엽니다.

```powershell
npm ci
node scripts/docs-preview.mjs
```

Edge에서 `http://127.0.0.1:4175/`에 접속합니다. 주소 뒤에 `?view=값`을 붙이면 기능별 화면이 열립니다. 모든 데이터는 표본이며 외부와 통신하지 않습니다.

| 주소 | 확인할 기능 |
|---|---|
| `/?view=inbox` | **공유/공람 브리핑** — 기한 임박·내 업무·단순 공람 분류와 이유, 일정 등록, 맞음/틀림 |
| `/?view=workplan-chat` | **/업무계획 카드** — 수신 요청·해야 할 일·근거(원문 확인 배지)·회신 준비, 일정으로 등록, 회신 기안으로 보내기 |
| `/?view=schedule` | **일정 탭** — 월·주·일·목록 보기, D-day, CSV·ICS 내보내기 |
| `/?view=automation` | **도구 탭** — 본문·첨부 일괄 다운로드 작업과 기록 |
| `/?view=drafter` | **기안 코파일럿** — 서식 선택·초안 작성·제목 반영 |
| `/?view=drafter-refs` | 참고자료 선택(최대 3건)·내용 근거/작성 예시 지정·분석 |
| `/?view=templates` | 서식 관리 — 표준 4종, 파일에서 서식 가져오기(HWPX·ODT) |
| `/?view=drafter-review` | **문장 다듬기(퇴고)** — 맞춤법 검사, 변경 전후 비교, 항목별 제외 |
| `/?view=drafter-workplan` | 업무계획에서 넘어온 회신 준비 카드와 요구사항 점검 |
| `/?view=onnara-main-sidepanel`, `/?view=onnara-drafter-sidecar` | 온나라 화면(모사 틀)과 사이드패널·사이드카가 나란히 작동하는 모습 |

> 미리보기의 AI 응답은 표본입니다. 실제 AI 추론은 방법 B에서 확인합니다.

### 방법 B. 확장 프로그램 설치 — 실제 온나라 + 로컬 AI 환경

1. Ollama를 설치하고 모델을 받습니다.
   ```powershell
   ollama pull gemma4:e2b
   ollama pull bge-m3:latest
   ```
2. 시스템 환경 변수 `OLLAMA_ORIGINS`를 `chrome-extension://*`로 설정하고 Ollama를 다시 시작합니다.
3. `onnara-saide-0.1.0-edge.zip`을 풀고, Edge 주소창에 `edge://extensions`를 입력 → **개발자 모드** 켜기 → **압축 해제된 확장 로드** → 푼 폴더를 선택합니다.
   (소스에서 직접 만들려면 `npm ci` → `npm run build` 후 `.output/edge-mv3` 폴더를 선택합니다.)
4. 툴바의 확장 아이콘을 고정하고 클릭(또는 `Alt+Shift+A`)하면 오른쪽에 사이드패널이 열립니다.
   확장 ID는 `manifest.key`로 `popnobbmpmholgejlcflnkmicegjmjah`에 고정되어 있어, 어느 폴더에 풀어도 같은 ID로 설치됩니다(일정·설정이 폴더 경로에 묶이지 않습니다). 단, 불러온 폴더를 **지우면 확장이 꺼지고 Edge가 저장 데이터도 함께 지웁니다.**
5. 온나라 2.0에 로그인한 뒤 `공유/공람 > 받은문서` 또는 문서등록대장에서 공문을 체크하고, AI 탭에서 `/업무계획`을 입력합니다. 기안기 화면에 들어가면 오른쪽에 **기안 코파일럿** 사이드카가 자동으로 붙습니다.

## 4. 기능 사용 순서 (실제 환경)

1. **공유/공람** 탭 — `이 화면을 브리핑 대상으로 지정` → `지금 확인`으로 받은문서 분류 확인
2. 공문 체크 → **AI** 탭에서 `/업무계획` (첨부문서 분석 포함 선택 가능) → 카드 확인
3. `일정으로 등록`(확인 카드에서 항목 체크) → **일정** 탭에서 달력·D-day 확인
4. `회신 기안으로 보내기` → 기안기 화면의 **기안 코파일럿**에서 참고자료·서식을 고르고 `공문서 초안 생성`
5. `위치 지정`(클릭한 자리에 삽입) 또는 `본문에 삽입`, 추천 제목 `제목 반영`
6. **문장 다듬기** 탭에서 맞춤법 검사·변경 전후 비교 후 반영, 초안 생성 뒤 `요구사항 점검`으로 회신 요구사항 충족 확인

## 5. 검증과 재생성 명령

```powershell
npm run compile        # 타입 검사
npm test               # 단위·통합 시험 (131개 파일, 1,473건 — 2026-11-18 통과)
npm run build          # Edge·Chrome MV3 번들 → .output/
npm run verify         # 빌드 무결성 + WCAG AA 색상 대비 검사
npm run zip            # 확장 배포본 → .output/onnara-saide-0.1.0-edge.zip
npm run package:source # 소스 패키지 → release/ (+ 배포본 복사, SHA256SUMS.txt)
npm run release        # 위 build·verify·zip·package:source 일괄
```

`npm run test:live`는 로컬 Ollama가 켜져 있을 때만 쓰는 실모델 점검이며 기본 시험에는 포함되지 않습니다.

## 6. 알려진 제약 사항

- 온나라 연동 기능(목록·본문 회수, 기안기 삽입)은 온나라 2.0 로그인과 해당 화면이 필요하므로, 심사 환경에서는 방법 A의 모의데이터와 제출서류의 화면 캡처로 확인합니다.
- AI 기능은 Ollama와 모델 설치(약 7 GB)가 필요하며, CPU 환경에서는 문서 1건 분석에 수십 초가 걸립니다(실측: 업무계획 카드 약 20~40초).
- 범정부 AI 공통기반 등 외부 AI 공급자 연동은 구현하지 않았습니다. 현재 추론 경로는 로컬 Ollama 한 갈래이며, 기본 설정에서 공문 본문은 PC 밖으로 나가지 않습니다.
- 담당자 배부 추천·개인정보 탐지기·반복 일정은 미구현입니다. 구형 `.hwp`, 스캔 PDF, 이미지는 분석하지 않습니다(HWPX·PDF로 저장 안내).
- 서식 적용 삽입은 기안기 환경에 따라 서식값 → 서식 있는 HTML → 글자 순으로 낮춰 적용하고 결과를 안내합니다.
- 온나라 서버 주소(도메인·내부 IP)는 설정하지 않습니다. 온나라 화면을 주소가 아니라 경로와 화면 구조로 알아보고 그 화면의 주소로 요청하므로, 다른 기관에서도 같은 설치본이 그대로 동작합니다.
- 온나라 화면 구조가 바뀌면 화면 어댑터 보정이 필요합니다.
- 압축 해제 확장은 Edge를 다시 켤 때 "개발자 모드 확장 프로그램을 사용 중지하시겠습니까?" 경고가 뜰 수 있습니다(끄지 않으면 됩니다). 이 경고는 웹 스토어를 거치지 않는 설치 방식의 한계입니다.
- 화면 캡처 중 `00-onnara-*.png` 두 장은 실제 온나라 화면이며 개인정보와 공문 목록을 모자이크로 비식별했습니다. 나머지는 표본 데이터입니다.
