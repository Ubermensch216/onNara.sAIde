# 온나라 sAIde

온나라 시스템 오른쪽에서 문서 이해, 배부 판단, 기안·교정, 업무 지식 검색을 지원하는 Microsoft Edge 확장 프로그램입니다. 로컬 Ollama와 범정부 AI 공통기반을 같은 공급자 인터페이스로 연결하는 것을 목표로 합니다.

현재 코드는 검증된 `sAIde` 사이드패널을 기반으로 독립시킨 구축 초기 버전입니다. 로컬 Ollama 연결과 일반 웹페이지 보조 기능은 기준선으로 유지하고, 온나라 화면 연결부와 업무 기능을 단계적으로 추가합니다.

현재 온나라 받은문서 화면에서 다음과 같이 요청하면, 접근 가능한 iframe의 문서 표를 다시 읽어 현재 화면에 표시된 모든 제목을 Markdown 표로 반환합니다.

> 받은문서 메뉴에 리스트업된 모든 문서의 제목을 읽어서 테이블로 만들어줘.

문서등록대장이나 받은문서 목록에서 제목을 지정해 요약을 요청할 수도 있습니다.

> '감사결과 처분요구 이행실태 특정감사 자료 제출' 문서를 읽고 핵심 내용을 요약해줘.

sAIde는 현재 목록에서 제목을 정확히 대조한 뒤 원본 화면을 유지하고, 임시 백그라운드 탭에서 문서를 열어 본문을 읽습니다. 같은 iframe, 탭 전환, 새 팝업 방식을 모두 감시하며 작업이 끝나면 임시 탭을 닫습니다. 별도 창으로 뜨는 팝업은 탭 opener 정보가 없어 창 열림 이벤트로 추적해 문서마다 닫고, 같은 이름의 기존 팝업 창이 재사용되면 그 창에서 요청한 제목이 보일 때만 읽고 닫지 않습니다. 본문이 목록과 다른 주소(전용 뷰어 등)의 프레임에 있어 사이트 권한이 없으면 기다리지 않고 해당 주소를 알려 주며, 오류 배너의 "권한 허용"은 그 주소를 요청합니다. 문서 제목을 눌러도 15초 동안 새 창이나 화면 이동이 없으면 팝업 차단으로 안내합니다. 제목이 없거나 여러 문서와 겹치면 임의로 열지 않고 제목을 더 정확히 입력하도록 안내합니다.

사이드패널을 열어 둔 동안 다른 페이지나 탭으로 이동해도 문서별 요약 작업은 유지됩니다. 원래 페이지로 돌아오거나 대화 목록에서 선택하면 읽은 본문, 진행 상태와 결과를 이어서 볼 수 있습니다. 패널을 닫거나 브라우저를 종료한 뒤에는 저장된 대화만 복원되며 진행 중이던 작업은 자동 재개되지 않습니다.

사용자·AI 말풍선 아래의 복사 아이콘은 본문 전체를 클립보드에 복사하고, 삭제 아이콘은 해당 메시지만 저장 이력에서 삭제합니다. 생성 중에는 개별 삭제가 비활성화됩니다. 상단의 **현재 대화 초기화** 아이콘은 현재 작업을 중단하고 해당 세션의 대화와 첨부 문맥을 비웁니다. 다른 세션은 유지됩니다.

이 기능은 이미지 인식이 아니라 DOM의 `제목` 열과 각 행을 읽습니다. 페이지를 넘겨야 보이는 문서는 자동으로 포함하지 않으며, 답변에 현재 렌더링된 목록 기준임을 표시합니다.

## AI 탭과 도구 탭

사이드패널은 두 탭으로 나뉩니다.

- **AI**: 문서를 읽고 판단하거나 글을 쓰는 기능입니다. 결과는 틀릴 수 있어 답변마다 "AI 생성 · 검토 필요"로 표시됩니다. 온나라 목록에서 체크한 문서마다 **핵심·조치사항** 카드(요지·할 일·제출물·기한·문의처·근거 문장)를 만들 수 있습니다. 모델은 JSON 형식으로만 답하고, 근거 문장과 기한 날짜는 코드가 원문과 대조해 "원문 확인" 또는 "원문에서 찾지 못함"으로 표시합니다. 모델이 빠뜨린 "…까지" 기한은 코드가 원문에서 찾아 덧붙입니다.
- **도구**: AI 모델 없이 온나라 화면의 기존 기능만 사용하는 작업입니다. Ollama가 꺼져 있어도 동작합니다. 체크한 문서의 **첨부 받기**, 현재 목록을 엑셀에서 여는 CSV로 저장하는 **목록 내보내기**를 제공합니다. 작업은 대기열에서 한 건씩 실행되고, 실행 기록은 패널을 다시 열어도 남으며, 파일 이름을 누르면 파일이 열리고 "폴더 열기"를 누르면 저장 위치가 열립니다. 내보낸 CSV는 `=`, `+`, `-`, `@`로 시작하는 값을 수식으로 실행하지 않도록 처리합니다.

AI 탭 대화에서 "첨부 파일을 다운로드해줘", "목록을 엑셀로 내보내줘"라고 요청해도 같은 자동화 작업으로 실행되고, 결과는 "자동화 실행 기록"으로 표시되며 도구 탭 기록에도 남습니다.

## 개발 환경

첨부 다운로드: 문서를 열고 **문서에 첨부된 자료를 모두 다운로드해줘**, 또는 목록에서 체크한 뒤 **선택한 문서들의 첨부파일을 모두 다운로드해줘**라고 요청합니다. 확인 가능한 일반 HTTP(S) 첨부 링크를 한 파일씩 내려받고 Edge가 완료를 보고한 뒤 다음 파일로 넘어갑니다. AI 모델은 호출하지 않습니다. 저장 위치는 Edge 다운로드 설정을 따르며 같은 이름은 덮어쓰지 않습니다. 완료된 파일은 답변에 실제 저장 경로로 표시되며, 경로를 누르면 기본 프로그램으로 열리고 **폴더 열기**를 누르면 탐색기에서 파일 위치가 열립니다. 파일을 옮겼거나 Edge 다운로드 기록을 지웠으면 그 이유를 안내합니다. **선택한 문서의 내용을 각각 요약하고, 첨부 파일도 모두 다운로드해줘**처럼 함께 요청하면 문서마다 상세 화면을 한 번만 열어 본문을 읽고 첨부를 받은 뒤, 요약 아래에 그 문서의 첨부 결과를 붙입니다. 여러 문서를 처리할 때는 복제한 목록 탭 하나를 끝까지 재사용하고 작업이 끝나면 닫습니다. 전용 보안 프로그램·JavaScript 버튼·POST 방식은 아직 지원하지 않습니다. 실제 기관 온나라 다운로드 동작은 미검증입니다.

체크박스로 문서를 선택한 뒤 **이 문서들의 내용을 요약해줘**라고 요청할 수 있습니다. **전체 문서를 읽고 요약해줘**는 현재 페이지에 표시된 목록 전체를 처리합니다. 다른 페이지까지 자동으로 이동하지는 않습니다. 여러 문서는 한 건씩 읽고 요약하며 완료된 결과부터 표시합니다. 중단 버튼으로 남은 작업을 취소할 수 있습니다.

일반 대화와 에이전트의 AI 응답은 시간 제한 없이 기다립니다. 모델 로딩이나 CPU 분석 중 응답이 없어도 자동 중단하지 않고 완료된 답변을 표시하며, 사용자가 중단 버튼을 누르면 취소됩니다. 기존에 저장된 무응답 대기 한도는 적용하지 않습니다. 실제 서버 오류나 연결 종료는 오류로 안내합니다. 문서 화면 읽기는 문서당 120초 제한이며 AI 추론 시간과 별도로 처리합니다. 복제 탭이 초기 화면으로 돌아가면 원본에서 확인한 목록 iframe 주소와 조회 폼의 검색·페이지 조건으로 복원을 시도합니다. 목록 자신을 대상으로 하는 GET/POST 조회 폼만 사용하며 선택 문서 행과 실행 버튼은 재전송하지 않습니다. 복제 탭의 초기 로딩이 끝난 뒤 복원하며, 목록이 나타나지 않으면 최대 3회까지 다시 복원합니다. 40초 안에 목록을 복원하지 못하면 마지막으로 본 작업 탭 화면과 함께 해당 문서를 직접 열어 요약하도록 안내합니다. JavaScript 메모리에만 있는 조회 상태나 전용 본문 뷰어는 추가 어댑터가 필요할 수 있으며 실제 기관 환경에서의 복원 동작은 미검증입니다.

- Microsoft Edge / Manifest V3
- Node.js 24.x, npm 11.x
- WXT, React, TypeScript
- Ollama 0.34.1
- 기본 대화 모델 `gemma4:e2b`
- 기본 임베딩 모델 `bge-m3:latest`

## 시작하기

```powershell
npm ci
Copy-Item .env.example .env.local
npm run compile
npm test
npm run build
npm run verify
```

빌드 결과는 `.output/edge-mv3`에 생성됩니다. Edge의 `edge://extensions`에서 개발자 모드를 켜고 **압축 풀린 확장 로드**로 이 폴더를 선택합니다.

`.env`의 `WXT_` 변수는 빌드 결과에 포함됩니다. API 키나 토큰은 `.env`에 넣지 않습니다. 운영 인증은 사용자 설정 또는 기관 내부 게이트웨이를 사용합니다.

## 보안 원칙

- 온나라 페이지 읽기는 사용자가 호출한 시점에 필요한 권한만 요청합니다.
- 외부 공급자 전송 전에는 기관 정책과 민감정보 검사를 적용합니다.
- 문서 배부와 시스템 입력은 추천과 초안까지만 자동화하고 최종 실행은 사용자가 확인합니다.
- 확장 저장소를 비밀 저장소로 간주하지 않습니다.
